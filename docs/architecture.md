# Архитектура

Приложение — локальный веб-клиент React/TypeScript и API FastAPI. Старый Streamlit UI удалён; совместно используемая Python-бизнес-логика сохранена в `src/` и вызывается backend.

- `frontend/`: React-интерфейс, маршрутизация, кэширование API-запросов и графики.
- `backend/app/main.py`: FastAPI-приложение, CORS и загрузка датасета при старте.
- `backend/app/api/`: REST-эндпоинты компаний, операций, прогноза, риска и будущих событий.
- `backend/app/services/data_loader.py`: чтение кейсовых CSV, нормализация знаков, сохранение ИНН строками и проверка дневных остатков.
- `backend/app/core/storage.py`: локальное SQLite-хранилище пользовательских категорий, подтверждений серий и событий.
- `src/data/preprocessing.py`: агрегация ежедневных рядов.
- `src/categorization/`: правила объяснимой классификации и текстовый классификатор.
- `src/recurring/`: обнаружение повторяющихся серий.
- `src/future_events/`: проверка будущих событий и объединение потоков с устранением повторного учёта.
- `src/forecasting/`: baseline/ML-модели, walk-forward оценка и построение баланса.
- `src/risk/`: анализ порога резерва и bootstrap-оценка вероятности.

Backend загружает основной датасет один раз при запуске и сообщает его состояние через `GET /api/health`. CSV-датасет хранится локально и не коммитится. Демо-файлы в `data/demo/` оставлены для тестов прежних Python-модулей; FastAPI и React не используют их как fallback.
